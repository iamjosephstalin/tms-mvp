# DialFi - Telecalling Management System

**DialFi** (formerly TMS) is a modern, enterprise-grade Telecalling Management System designed to streamline lead management, agent productivity, and team performance tracking.

## 🚀 Features

- **Role-Based Access Control:** Distinct dashboards for **Telecallers**, **Team Leads**, and **Super Admins**.
- **Lead Management:**
  - Automated and manual lead assignment.
  - Lifecycle tracking (New -> Follow-up -> Sanctioned -> Disbursed).
  - Bulk upload capabilities.
- **Performance Dashboards:**
  - Real-time metrics for calls, conversions, and SLAs.
  - Interactive charts and date-based filtering.
- **Reporting:**
  - comprehensive reports (DAR, Productivity, Conversions).
  - Export functionality (CSV, Excel, PDF support).

## 🛠️ Tech Stack

- **Frontend:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Enterprise "Slate" Theme)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Charts:** [Recharts](https://recharts.org/)
- **Routing:** [React Router](https://reactrouter.com/)

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd tms-mvp
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
